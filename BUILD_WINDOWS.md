# Сборка для Windows

1. Распакуйте весь архив в отдельную папку на Windows.
2. Установите 64-битный Python 3 вместе с Python Launcher (`py`).
3. Запустите `build_windows.bat`. Для загрузки зависимостей нужен интернет.
4. После успешной сборки готовый файл будет в `dist/HybridInterface.exe`.

Скрипт создаёт отдельное окружение `.venv-windows`, устанавливает зависимости и собирает приложение с приёмом LSL, графиками и полем массива. Установленный Python на компьютере, где затем запускается `.exe`, не требуется.

Используется первый найденный поток типа `EEG` или `Signal`. Последний блок отображается под графиками и доступен в коде как `window.signal_array`.

Также включена подсистема P300 с MNE, SciPy и scikit-learn. Скрипт сборки
устанавливает закреплённую liblsl 1.17.7 с проверкой SHA-256.
Порядок калибровки и протокол внешних маркеров: [docs/P300.md](docs/P300.md).
