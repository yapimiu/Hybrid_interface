# Сборка для Windows

1. Распакуйте весь архив в отдельную папку на Windows.
2. Установите 64-битный Python 3 вместе с Python Launcher (`py`).
3. Запустите `build_windows.bat`. Для загрузки зависимостей нужен интернет.
4. После успешной сборки готовый файл будет в `dist/HybridInterface.exe`.

Скрипт создаёт отдельное окружение `.venv-windows`, устанавливает зависимости и собирает приложение с приёмом LSL, графиками и полем массива. Установленный Python на компьютере, где затем запускается `.exe`, не требуется.

Используется самый новый поток типа `EEG` или `Signal`; поток без отсчётов пропускается. Последний блок отображается под графиками и доступен в коде как `window.signal_array`.

Также включена подсистема P300 на ядре `hybrid-bci-p300-ssvep` с SciPy.
MNE и scikit-learn больше не требуются. Скрипт сборки
устанавливает закреплённую liblsl 1.17.7 с проверкой SHA-256.
Порядок запуска оригинального анализатора и стимулятора: [docs/P300.md](docs/P300.md).
Для кнопок запуска стимулятора/протокола отдельно подготовьте Python 3.10
через `setup_pronin_windows.bat` и выберите `.venv-pronin\Scripts\python.exe`
во вкладке «Запуск и проверка». Для самого EXE и встроенной синтетической
проверки это окружение не требуется.
