# Инструкция пользователя Hybrid Interface

Пошаговое описание: что нажимать, чтобы получить запись ЭЭГ, массив P300 и архив эксперимента.

## Что умеет программа

В окне четыре вкладки:

| Вкладка | Для чего |
| --- | --- |
| **Единый эксперимент** | Основной сценарий P300. Одна кнопка запускает стимулятор, проводит серию проб и сохраняет всё в архив. |
| **EEG — графики и CSV** | Просмотр сигнала из LSL, запись сырых данных в CSV, сохранение графиков в PNG. |
| **P300 — анализатор Пронина** | Настройки анализа (каналы, окно, порог артефактов) и ручной анализ P300. |
| **Запуск и проверка** | Запуск стимулятора Пронина и проверка P300 без оборудования. |

Программа сама ЭЭГ не генерирует. Она принимает поток от внешнего источника по LSL: от Нейрон-Спектра или другого энцефалографа.

## 1. Подготовка (один раз)

### 1.1. Программа

Запустите `HybridInterface.exe`. Python для этого не нужен.

> Сборка с исправлениями от 17.10.2026 (выбор живого потока, запуск эксперимента с Нейрон-Спектром) лежит в `dist/fixed/HybridInterface.exe`. В более старой сборке «Единый эксперимент» с Нейрон-Спектром не запускается.

### 1.2. Окружение стимулятора (только для P300)

Стимулятор Пронина работает в отдельном Python 3.10 с PsychoPy. Один раз запустите `setup_pronin_windows.bat`: он создаст папку `.venv-pronin`. Для просмотра и записи ЭЭГ этот шаг не нужен.

### 1.3. Нейрон-Спектр

1. **Настройки → Изменить… → Анализ → Сторонние программы.** В блоке «Передача ЭЭГ-данных в реальном времени (LSL)» поставьте флажок «Автоматически запускать экспорт ЭЭГ-данных при старте обследования». Нажмите **OK**.
2. Частота и фильтры (при необходимости): **Настройки → Стили регистрации**.
   - **Аппаратура → Частота квантования** — например, 1000 Гц.
   - **Фильтрация** — ФВЧ, ФНЧ, режекторный фильтр.

   Нажмите **OK** и подтвердите сохранение стиля. Новые настройки действуют только в **новом** обследовании.

> **Важно.** Нейрон-Спектр передаёт поток в LSL только в режиме **«Запись»**. В режиме «Мониторинг» потока нет.

## 2. Просмотр и запись ЭЭГ в CSV

Вкладка **«EEG — графики и CSV»**.

1. В Нейрон-Спектре создайте обследование (**Новое обследование → OK**) и нажмите **«Запись»**.
2. Откройте Hybrid Interface. В левой колонке статус «Поиск LSL потока EEG/Signal...» сменится на «Поток: NeuronSpectrum …», появятся частота и счётчик «Сэмплов». На графиках пойдёт сигнал всех каналов.
3. Убедитесь, что счётчик «Сэмплов» растёт. Если он стоит на 0, см. раздел 7.
4. Нажмите **«Начать запись в CSV»** и выберите имя файла. Кнопка сменится на **«Остановить и сохранить»**, под ней появится «Идёт запись: N отсчётов».
5. Когда записали нужное, нажмите **«Остановить и сохранить»**. Только **после этого** останавливайте запись в Нейрон-Спектре (**«Стоп»**).

Запись в CSV должна идти, пока идёт «Запись» в Нейрон-Спектре. Если сначала остановить Нейрон-Спектр, в файл попадёт только заголовок.

**Что получится.** CSV, в первой строке `lsl_timestamp_s` и имена каналов, дальше одна строка на каждый отсчёт. Значения сырые, в единицах источника: у Нейрон-Спектра это микровольты. Разделитель — запятая, десятичный знак — точка, кодировка UTF-8 с BOM.

> Нейрон-Спектр ставит метки времени LSL с шагом 1 секунда, по часам Windows. Поэтому в столбце `lsl_timestamp_s` подряд идут одинаковые значения. Сами отсчёты при этом не теряются: порядок строк соответствует порядку отсчётов прибора.

**Другие элементы вкладки:**
- **«Сохранить графики (PNG)»** — картинка со всеми каналами.
- **«Автомасштаб Y»**, **«Масштаб Y (мкВ)»** (Мин/Макс), **«Масштаб X (с)»** (Окно) — только вид графиков, на запись не влияют.
- **«Последний принятый массив»** — значения последнего принятого блока: строки — отсчёты, столбцы — каналы. Их можно выделить и скопировать.

## 3. Единый эксперимент P300 (основной сценарий)

Программа сама запускает стимулятор Пронина (окно с 9 плитками), подключает его метки, проводит серию проб и сохраняет EEG, события, эпохи, суммы и результаты в отдельную папку.

> Нейрон-Спектр передаёт по LSL только ЭЭГ, моменты вспышек он не передаёт. Метки стимулов в эксперименте всегда даёт стимулятор Пронина.

### 3.1. Проверьте настройки анализа

Вкладка **«P300 — анализатор Пронина»**, левая колонка:

1. **«Единицы входной EEG (для P300):»** — `uV` для Нейрон-Спектра.
2. **«Каналы ROI:»** — флажки каналов, по которым ищется P300.
   - По умолчанию отмечены каналы 5–8 и 19–20. **У Нейрон-Спектра канал 20 — это ЭКГ.** Снимите с него флажок.
   - Рекомендуется: **P3, P4, CZ, PZ**. Кнопки **«Все»** и **«Сброс»** отмечают все каналы или снимают все отметки.
3. **«Baseline (мс):»** — участок до вспышки для коррекции базовой линии, по умолчанию 100.
4. **«Начало окна X (мс):»** и **«Конец окна Y (мс):»** — окно, в котором ищется ответ.
   - По умолчанию (пресет «Общий») — 550–725 мс. Пресет «Последние 7» — 375–675 мс.
   - Окно должно накрывать пик P300 в ваших данных. На синтетическом испытуемом с P300 на 300 мс окно 550–725 мс дало 0 верных из 3, а окно 250–500 мс — 3 из 3.
5. **«Порог артефактов (мкВ, 0=выкл):»** — эпохи с амплитудой выше порога не усредняются. По умолчанию 60.
6. **«CAR»** — общий средний референт. Оставьте выключенным, если включён канал ЭКГ.

Способ выбора объекта в эксперименте фиксирован: AUC анализатора Пронина. Во время сессии эти настройки заблокированы.

### 3.2. Укажите Python стимулятора

Вкладка **«Запуск и проверка»** → поле **«Python окружения Пронина:»**. Если `.venv-pronin` лежит рядом с программой, путь подставится сам. Иначе нажмите **«Выбрать…»** и укажите `.venv-pronin\Scripts\python.exe`.

### 3.3. Запустите сессию

1. В Нейрон-Спектре идёт **«Запись»**, а в Hybrid Interface растёт счётчик «Сэмплов».
2. Вкладка **«Единый эксперимент»**. Строка готовности сверху должна показывать имя EEG-потока и число отсчётов.
3. Заполните **«Параметры сессии»**:

   | Поле | Что ввести |
   | --- | --- |
   | Испытуемый | Код, например `S01` (обязательно) |
   | Проб в сессии | Сколько раз искать объект (1–200), по умолчанию 5 |
   | Вспышек каждой плитки за пробу | 5–40, по умолчанию 12 |
   | Seed плана целей | Задаёт повторяемый план целевых плиток |
   | Пауза между пробами, с | 0–60 |
   | Сохранение экспериментов | Папка архивов (кнопка **«Выбрать папку…»**) |

4. Нажмите **«Начать единый эксперимент»**.

### 3.4. Во время сессии

- Откроется окно стимулятора с 9 плитками. Перед каждой пробой показывается **целевая плитка**. Испытуемый смотрит на неё и мысленно считает её вспышки.
- Статус над таблицей показывает этап: «Подготовка…», «Проба 1/5…», «Получен trial_end…», «Проба сохранена».
- **«Объект внимания»** — предварительный результат текущей пробы.
- Внизу — **«Сумма эпох по объектам: текущая / последняя проба»**: живой массив P300 (см. 3.6).
- Остановить досрочно: **«Остановить и закрыть архив»**. Незаконченная проба сохранится со статусом `interrupted`.

Не нажимайте кнопки на вкладке P300 и не закрывайте стимулятор вручную: сессия прервётся.

### 3.5. Результат

После каждой пробы в таблице появляется строка:

| Столбец | Значение |
| --- | --- |
| Проба | Номер |
| Предъявленная цель | Плитка, на которую смотрел испытуемый |
| Предполагаемый объект | Плитка, выбранная анализатором |
| Чистых эпох минимум | Наименьшее число пригодных эпох среди 9 плиток |
| Результат | «Выбор получен» или «Недостаточно пригодных данных» |

«Недостаточно пригодных данных» означает, что для какой-то плитки меньше 5 эпох прошли порог артефактов. Программа в этом случае объект не угадывает.

### 3.6. Массив P300 (сумма эпох по объектам)

Каждая вспышка плитки даёт эпоху. Эпохи одной плитки складываются поточечно: для каждого канала получается одна кривая. Переключатель **«Вывод:»**:

- **Вариант 1: единый массив** — таблица, строки — время от вспышки (мс), столбцы — `объект_канал` (например `4_PZ`), значения — сумма эпох в мкВ.
- **Вариант 2: одно число на объект** — средняя амплитуда (сумма / число вспышек) в окне X–Y после baseline. Максимум помечен «← максимум».

Значения можно выделить и скопировать в Excel.

### 3.7. Где архив

По умолчанию — `Документы\Hybrid Interface\experiments\session_ДАТА_ВРЕМЯ_код\`:

| Файл | Содержимое |
| --- | --- |
| `session.json` | Испытуемый, план, параметры анализа, описание EEG-потока, итог (`recording_complete`, `protocol_complete`) |
| `eeg.csv` | Вся ЭЭГ сессии с исходными метками времени LSL |
| `events.jsonl` | Все метки стимулятора и смены этапов |
| `stim_control.json` | Управляющий файл стимулятора |
| `trial_001\result.json` | Цель, выбранный объект, оценки, число пригодных эпох |
| `trial_001\epochs.npz` | Эпохи каналов ROI для каждой вспышки |
| `trial_001\erp_sums.npz` | Массив сумм (объекты × отсчёты × каналы), средние, вариант 1 и вариант 2 |
| `trial_001\erp_unified.csv` | Вариант 1 для Excel |
| `trial_001\erp_numbers.csv` | Вариант 2 для Excel |
| `trial_001\upstream_run.json` | Полная исходная выгрузка пробы анализатором Пронина |

## 4. Ручной анализ P300 (без «Единого эксперимента»)

1. Вкладка **«Запуск и проверка»** → **«Запустить стимулятор Пронина»**. Откроется окно плиток с панелью параметров справа. Пока не нажимайте **START**.
2. Вкладка **«P300 — анализатор Пронина»**:
   1. проверьте единицы и каналы (3.1);
   2. **«Имя потока маркеров:»** — `BCI_StimMarkers`;
   3. нажмите **«Подключить маркеры P300»** и дождитесь строки «Маркеры: BCI_StimMarkers»;
   4. нажмите **«Начать анализ»**.
3. В окне стимулятора нажмите **START**. Испытуемый смотрит на указанную цель. **Space** останавливает мигание, **Esc** закрывает стимулятор.
4. На вкладке P300 следите за полем **«РЕЗУЛЬТАТ»** и графиками ERP. Решение появляется после 5 эпох каждой плитки.
5. Нажмите **«Остановить анализ»**, затем **«Сохранить обследование»**. В диалоге выберите:
   - **Формат:** CSV, TXT или XLSX;
   - **Что сохранять:** одна плитка, все плитки в один файл или вся ЭЭГ прогона непрерывно;
   - **Каналы:** все, только ROI или вручную.
6. **«Отключить LSL»** — отключить маркеры. **«Остановить запущенные компоненты»** на вкладке «Запуск и проверка» закрывает стимулятор.

Массив сумм по объектам виден внизу вкладки P300 (те же два варианта, что в 3.6).

## 5. Проверка без оборудования

Вкладка **«Запуск и проверка»** → **«Проверка P300 без оборудования (симулятор Пронина)»**. Это исходная синтетическая проверка Пронина. Ожидаемый итог: `"both_decide": 2`. Отчёт сохраняется в `Документы\Hybrid Interface\p300_synthetic_validation.json`. Это проверка программы на искусственных данных, а не запись ЭЭГ.

## 6. Закрытие

Закройте окно программы. Идущая запись CSV сохранится, стимулятор будет остановлен, архив эксперимента закроется. Окно может закрыться не сразу: программа ждёт завершения фоновых процессов.

## 7. Частые проблемы

| Что видно | Причина и что делать |
| --- | --- |
| «Поиск LSL потока…» не меняется | В Нейрон-Спектре не нажата «Запись» или не включён экспорт LSL (1.3) |
| Поток найден, «Сэмплов: 0», каждые ~5 с переподключение | Программа подключилась к потоку остановленной записи. Новая сборка сама переходит на живой поток через ~6 с. Старая не переходит: закройте лишние обследования и копии Нейрон-Спектра |
| В CSV только заголовок | Запись CSV начата после остановки Нейрон-Спектра (раздел 2, п. 5) или см. строку выше |
| «EEG-поток найден, но свежие отсчёты не поступают» | Нет данных дольше 2,5 с. Проверьте «Запись» в Нейрон-Спектре |
| «Выберите EEG-каналы ROI на вкладке P300» | Не отмечен ни один канал (3.1) |
| «Выберите Python окружения Пронина…» | Не указан Python стимулятора (3.2) |
| «Остановите отдельный анализ/стимулятор/протокол…» | Отдельно запущен стимулятор или идёт ручной анализ. Остановите их |
| «Не удалось подключить маркеры за 35 секунд…» | Стимулятор не запустился. Смотрите журнал на вкладке «Запуск и проверка» |
| «EEG не передаёт свежие отсчёты более 3 секунд» | Поток ЭЭГ пропал во время сессии. Начните новую сессию |
| «Недостаточно пригодных данных» | Мало эпох прошло порог артефактов. Проверьте контакт электродов, увеличьте число вспышек |
| Эксперимент с Нейрон-Спектром не стартует, ошибка `utf-8 codec can't decode` | Старая сборка. Используйте `dist/fixed/HybridInterface.exe` |

## 8. Ограничения

- Выбор объекта — описательная метрика анализатора Пронина, а не откалиброванная вероятность. Наличие P300 у человека она не доказывает.
- Привязка эпох к вспышкам у анализатора Пронина идёт по времени получения данных. На синтетическом испытуемом пик P300 оказывался на 16–114 мс позже истинного. Учитывайте это при выборе окна X–Y.
- Режим эмуляции Нейрон-Спектра выдаёт шум без вызванных ответов. Проверить P300 по нему нельзя, только работу программы.
