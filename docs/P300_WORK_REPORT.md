## 2. Независимое вычислительное ядро

Создан пакет `app/p300/`. Вычислительная часть используется без Qt
и без подключения к LSL; приёмники и интерфейс находятся в отдельных модулях.

| Файл | Что реализовано |
| --- | --- |
| `config.py` | Неизменяемая конфигурация, проверка параметров, явные единицы V/mV/uV, сериализация. |
| `buffer.py` | Ограниченный кольцевой буфер многоканальной EEG с timestamps, проверка порядка времени, поиск окон относительно стимулов. |
| `markers.py` | Строгий JSON-протокол стимулов с event_id, object_id, trial_id, block_id, objects и необязательной target-меткой. |
| `processing.py` | Выделение эпох, контроль качества, фильтрация MNE, ресемплинг SciPy, коррекция базовой линии и усреднение ERP по объектам. |
| `model.py` | Обучение Shrinkage LDA и xDAWN + LDA, проверка разбиений, отчёт о калибровке, числовое сохранение моделей. |
| `scoring.py` | Накопление оценок отдельно по объектам и trial, проверка числа повторений и неоднозначности выбора. |
| `engine.py` | Координация буфера, событий, калибровки, ERP, классификации, диагностик и записи эксперимента. |
| `storage.py` | Потоковая запись raw EEG и событий, сохранение конфигурации, эпох, моделей и результатов. |
| `offline.py` | Повторная обработка сохранённого эксперимента тем же ядром. |
| `__main__.py` | CLI-команды preprocess, train и evaluate. |
| `diagnostics.py` | Автоматическая проверка наличия научных зависимостей и нативной liblsl в приложении. |
| `__init__.py` | Публичные типы конфигурации и события. |

Параметры по умолчанию:

- Буфер EEG — 30 секунд; эпоха — от −0,2 до +0,8 секунды.
- Дополнительные данные для фильтрации — по 1 секунде с каждой стороны эпохи.
- MNE IIR Butterworth, порядок 4, полоса 0,5–20 Гц, нулевая фаза.
- SciPy resample_poly до 50 Гц; базовая линия — от −0,2 до 0 секунд.
- Внутренние амплитуды — в вольтах.
- Отбраковка NaN/Inf, отсутствующей предыстории, временных разрывов,
  нерегулярной сетки, плоских каналов и превышения порога амплитуды.
- Пороги peak-to-peak: артефакт выше 150 мкВ, плоский канал ниже 0,05 мкВ.

Фильтрация конечного интервала одинакова online и offline. Она использует
данные после стимула; стандартная задержка получения результата составляет
примерно 1,8 секунды после его начала.

## 3. Маркеры и синхронизация с EEG

Добавлен отдельный приёмник `MarkerReceiver` в `lsl.py`:

- Поиск потоков Markers/Marker и выбор по точному имени.
- Диагностика отсутствующего или неоднозначного потока.
- Приём JSON-маркеров внешнего визуального стимулятора и проверка полей.
- Сохранение исходного времени маркера и поправки часов.
- Переподключение и очистка текущих онлайн-оценок при потере маркеров.

В существующий EEG-приёмник добавлен отдельный сигнал
`p300_chunk_received`: исходные отсчёты, исходные timestamps и измеренная
поправка часов EEG. Контракт `chunk_received` для прежних графиков и CSV сохранён.

EEG и маркеры переводятся в локальный домен времени LSL собственными
time_correction каждого inlet. Событие привязывается к ближайшему
EEG-отсчёту; ошибка привязки сохраняется. Поддержан приход маркера
до EEG и после EEG в пределах доступного буфера. Дубликаты событий
и непригодные эпохи отбрасываются с диагностикой.

Также добавлены получение полных метаданных EEG-потока, диагностика
отсутствующей коррекции часов и повторный поиск после пяти секунд без EEG.

## 4. Калибровка, обучение и защита от утечек

Реализованы два фиксированных конвейера:

1. Vectorizer → StandardScaler → LDA с solver=lsqr, shrinkage=auto.
2. MNE XdawnTransformer с регуляризацией OAS →
   Vectorizer → StandardScaler → такая же LDA.

Обучение требует явных target/non-target меток. Проверяются достаточное
число эпох обоих классов, уникальность событий и согласованность меток
целевого объекта внутри trial.

Для внутренней оценки:

- GroupKFold разделяет целые block_id между train и test.
- Из train удаляются эпохи, исходные интервалы которых пересекаются с test,
  включая дополнительные данные для фильтрации.
- Для каждого fold создаётся новый Pipeline; xDAWN, StandardScaler и LDA
  обучаются только на его тренировочной части.
- Сохраняются индексы и ID разбиений, исходные интервалы, число исключённых
  эпох, оценки, метки, confusion matrix, balanced accuracy и ROC AUC.
- Автоматический выбор лучшего алгоритма по test-метрикам не выполняется.

После CV финальные модели обучаются на всей калибровке. Для воспроизводимости
сохраняются конфигурация, версии библиотек и SHA-256 датасета.
Числовой экспорт сверяется с предсказаниями обученного Pipeline.
Модели загружаются из NPZ с allow_pickle=False.

Онлайн-классификация не использует target-метку. Оценки накапливаются отдельно
для каждого trial. Предварительный выбор показывается только после достаточного
и равного числа принятых повторений всех объектов, при необходимом отрыве
первого места от второго. Без модели или маркеров показывается диагностика.

## 5. Интеграция с Qt

Добавлена панель `P300Panel` в `panel.py`, встроенная в существующее окно:

- Выбор EEG-каналов, физических единиц и дополнительных параметров JSON.
- Выбор потока маркеров.
- Начало и завершение записи эксперимента.
- Новая индивидуальная калибровка и обучение обеих моделей.
- Загрузка калибровки и моделей NPZ.
- Выбор алгоритма для онлайн-работы.
- Отображение диагностик, числа принятых/отклонённых эпох, оценок объектов
  и предварительного выбора.
- Графики ERP по объектам на выбранном канале, с числом усредняемых эпох.
- Отображение внутренних CV-метрик с указанием отсутствия независимой валидации.

В `worker.py` реализованы фоновый Qt-поток и ограниченная очередь команд.
Обучение вынесено в дополнительную задачу ThreadPoolExecutor, поэтому приём,
буферизация и запись продолжаются во время вычислений.
При переполнении очереди P300 останавливается с диагностикой; непрерывность
данных не считается сохранённой молча.

Добавлены корректное завершение потоков, ожидание обучения при закрытии,
сохранение результатов для исходного эксперимента при смене потока и защита
от активации старой модели на новом потоке.

В ходе проверки исправлено определение пути Qt-плагинов при расположении
окружения в каталоге с кириллицей.

Сохранены прежние просмотр каналов, последний сырой массив, статистика,
масштабирование, прокрутка, запись CSV и экспорт всех графиков в PNG.

## 6. Сохранение и offline-команды

Архив эксперимента содержит:

| Файл | Содержимое |
| --- | --- |
| `session.json` | Конфигурация, версии, метаданные потоков, время начала/конца, число отсчётов и признак complete. |
| `eeg.csv` | Сырые выбранные EEG-каналы, исходные и локальные timestamps, применённые поправки часов. |
| `events.jsonl` | Полученные валидные маркеры, идентификаторы, метки и время. |
| `results.jsonl` | Принятые и отклонённые эпохи, причины, ошибки привязки, онлайн-оценки и изменения состояния. |
| `epochs.npz` | Принятые эпохи последней калибровки, временная сетка, метки и исходные интервалы. |
| `calibration_report.json` | Отчёт об обучении и внутренней проверке, если обучение выполнено. |
| `shrinkage_lda.npz`, `xdawn_lda.npz` | Откалиброванные модели, если доступны. |
| `erp.npz` | Средние ERP, object_id и число эпох. |

Raw EEG и события записываются на диск по мере поступления. При ошибке
очереди/обработки/записи текущий эксперимент завершается с диагностикой;
признак complete позволяет отличить штатное завершение от неполного архива.

Добавлены команды:

```bash
python -m app.p300 preprocess /path/to/experiment /path/to/reprocessed.npz
python -m app.p300 train /path/to/epochs.npz /path/to/new_model_directory
python -m app.p300 evaluate /path/to/model.npz /path/to/heldout.npz /path/to/evaluation.json
```

Команда evaluate оценивает фиксированную модель без fit и отвергает
датасет с общими event_id или block_id из обучения.

## 10. Научные ограничения и оставшиеся проверки

**Независимая научная валидация на реальных размеченных данных не проведена.**
Реальные записи для такой проверки в ходе задачи не предоставлялись.
Синтетические EEG использовались только в автоматизированных тестах;
основной конвейер принимает реальные внешние записи/потоки.

Успешные тесты подтверждают технические свойства реализации, но не
достоверность распознавания P300 у конкретного участника.
Внутренняя CV не заменяет внешнюю проверку финальной модели.

Для научного использования ещё требуется:

1. Проверить систему с реальным усилителем и визуальным стимулятором,
   включая физические единицы, каналы и фактическое время начала вспышки.
2. Измерить аппаратные задержки дисплея и усилителя; time_correction
   синхронизирует часы, но не устраняет эти задержки.
3. Обосновать параметры фильтра, длину эпохи, padding и пороги артефактов
   для выбранного экспериментального протокола.
4. Проверить замороженную модель на независимых реальных размеченных данных
   с документированным происхождением и корректным разделением сеансов/блоков.
5. Проверить сборку и работу на Windows.

Текущий xDAWN-конвейер не выполняет коррекцию наложения ERP соседних стимулов.
Оценки LDA не являются клинической вероятностью P300.
Проверка ID не доказывает независимость датасетов при их ручном переименовании.
Межплатформенная побитовая идентичность вычислений BLAS не гарантируется.

Внешний визуальный стимулятор и реальные экспериментальные данные
не создавались. Предварительный выбор отображается в GUI; команды
внешним устройствам не отправляются.
