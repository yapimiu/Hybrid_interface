# Проверка интеграции — 16 октября 2026

Итоговый вариант использует исходное Qt-окно и алгоритмы Пронина без
переобучения и без нового классификатора. Промежуточный собственный модуль
калибровки в итоговую реализацию не включён.

- Полный запуск `pytest tests -q` с `RUN_LSL_NETWORK=1`: **66 passed**.
- Проверены исходные тесты P300, ERP, экспорт CSV/XLSX, разбор маркеров,
  профили, геометрия эпох и исходная синтетическая батарея.
- Проверено побайтовое совпадение всех перенесённых файлов с manifest
  исходного коммита `4e5dc7c0165da40c1ec2eacd633032c2415e31ec`.
- Проверена настоящая локальная передача LSL: исходный `SyntheticEEGInlet`
  → LSL outlet → `LSLReceiver` → исходный CSV и встроенный анализатор.
  Значения и timestamps CSV совпали с переданными; ERP-эпохи выделены.
- Проверены переполнение очереди, смена потока, устаревшее подключение,
  запуск дочернего процесса, `--no-analyzer` и остановка его дочерних процессов.
- Исходный `StimulusApp` PsychoPy 2026.1.0 инициализирован в оконном режиме
  в отдельном Python 3.10. Проба/мигание при этой проверке не запускались.
- Исходный `ProtocolRunnerWidget` инициализирован без старта сессии.
- Встроенная вкладка P300 отрисована для проверки расположения элементов.
- Windows EXE собран; `scripts/check_bundle.py` успешно проверил импорты,
  native liblsl, фильтр и исходную синтетическую батарею внутри EXE.

Без `RUN_LSL_NETWORK=1` сетевой smoke-test явно пропускается, остальные
тесты не требуют оборудования и сети. Полный прогон выше включает его.

## Окружения на этой машине

- `.venv-windows`: Python 3.12, numpy 2.2.6, scipy 1.15.3, pylsl 1.17.6,
  PyQt5 5.15.11, pyqtgraph 0.13.7, openpyxl 3.1.5.
- `.venv-pronin`: Python 3.10.22, PsychoPy 2026.1.0, scipy 1.14.1,
  зависимости из `requirements-pronin.txt`.
- В обоих окружениях установлена native liblsl 1.17.7.

Готовое приложение: `dist/HybridInterface.exe`.
Окружение PsychoPy хранится отдельно и не входит в этот EXE.

## Единый сценарий эксперимента

Последующая доработка добавляет общую вкладку управления серией P300-проб,
исходную очередь целей Пронина, его файловое управление стимулятором,
потоковую запись всей сессии и архив отдельных проб. Каналы EEG видны
до подключения маркеров; диагностика вынесена над ERP-графиками.

Полный прогон с локальными LSL-сокетами: **75 passed**. Дополнительно
проверены две последовательные пробы с исходными решениями P300, отсутствие
выбора при недостающих классах, ручная остановка с архивом прерванной пробы,
потеря EEG, неправильная cue-метка, падение стимулятора и запрет перезаписи
существующего архива. Штатный seed-план совпадает с исходной очередью Пронина.

Обновлённый EXE находится в **`dist/unified/HybridInterface.exe`**.
Он собран отдельно, поскольку Windows не разрешила заменить прежний файл.
Инструкция единого сценария: [EXPERIMENT.md](EXPERIMENT.md).

## Границы проверки

Датасеты, энцефалограф, аппаратная мигалка и реальные эксперименты отсутствуют.
Это не препятствовало проверке интеграции; работа с физическим оборудованием,
тайминги показа на целевом мониторе и точность на реальной EEG не измерялись.
macOS-сборка описана в CI, но локально проверена Windows-сборка.

Исходная синтетическая батарея возвращает `both_decide=2` для двух случаев.
Её `stable_rate` означает наличие решения в обоих режимах, а не точность:
в исходном случае с target=6 AUC выбирает 7, template_corr выбирает 6.
Этот результат и исходные алгоритмы сохранены без исправления/подгонки.
