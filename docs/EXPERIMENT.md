# Единый эксперимент EEG / ERP / P300

Вкладка **«Единый эксперимент»** управляет одной исследовательской сессией:
подготовкой записи, исходным PsychoPy-стимулятором, подключением маркеров,
началом/окончанием регистрации ERP и серией проб. Ручное переключение между
стимулятором и кнопками анализатора для каждой пробы больше не требуется.

## Подготовка

1. Запустите реальный EEG/Signal LSL-источник. Во вкладке EEG должны поступать
   отсчёты: обнаружения имени потока недостаточно для начала эксперимента.
2. На вкладке **P300** проверьте физические единицы EEG, каналы ROI, baseline,
   окно решения, CAR и порог артефактов. Каналы теперь видны сразу после
   подключения EEG, до поиска маркеров. Состояние P300 показано над графиками.
3. На вкладке **Запуск и проверка** укажите Python 3.10 окружения Пронина
   (`.venv-pronin/Scripts/python.exe` на Windows). Окружение создаётся через
   `setup_pronin_windows.bat`; PsychoPy остаётся версии 2026.1.0.
4. Во вкладке **Единый эксперимент** введите идентификатор испытуемого,
   число проб, повторений каждой плитки, паузу и папку архивов.
5. Нажмите **Начать единый эксперимент**. Другой ручной анализ или отдельно
   запущенный стимулятор/гибридный протокол должен быть предварительно остановлен.

Один повтор — одна случайная перестановка всех девяти плиток в исходном
стимуляторе. По умолчанию 12 повторений каждой плитки. Управляющая программа
использует `build_p300_block_queue` и `stim_control` из репозитория Пронина;
исходники и последовательность одного trial не переписаны.
Seed задаёт воспроизводимый **план целевых плиток**. Он не фиксирует порядок
вспышек PsychoPy: фактически предъявленные вспышки сохраняются в маркерах.

## Во время эксперимента

Программа запускает исходный `run_app.py --no-analyzer --auto-random-protocol
--stim-control-dir <сессия> --sequences <повторений>`. Сначала стимулятор
остаётся в состоянии ожидания. Затем программа подключает `BCI_StimMarkers`,
включает анализ и отправляет исходную команду `trial` для каждой пробы.

Испытуемый концентрируется на указанной в cue плитке. Случайный порядок
подсветки, timestamps событий и графика экрана остаются в PsychoPy.
Исходное ядро выделяет эпохи, усредняет ERP и вычисляет оценки объектов.

В едином сценарии используется **AUC исходного анализатора**. Параметры и
ручные кнопки P300 блокируются на время сессии, чтобы они не меняли обработку
посреди пробы. Настройки можно менять между сессиями. Режим template_corr
исходного окна, использующий известную cue-цель текущей пробы, остаётся
доступен отдельно; он не используется для независимого выбора объекта в
едином сценарии. Новый классификатор или новое обучение не создавались.

После `trial_end` программа ждёт полного ответа последней вспышки и обработки
ожидающих маркеров, останавливает регистрацию этой пробы, фиксирует результат
и начинает следующую после паузы. Эпохи разных проб не смешиваются.

Результат выдаётся при наличии как минимум **пяти пригодных эпох каждой из
девяти плиток**, конечных и различающихся оценок. Предварительный выбор
оригинального окна при меньшем числе встреченных классов не становится
итогом сессии. При недостаточных данных сохраняется `insufficient_evidence`
с пустым `winner`, а не произвольный объект.

Таблица показывает предъявленную cue-цель и рассчитанный объект отдельно.
Оценка AUC и margin не являются вероятностью внимания или самостоятельным
доказательством наличия физиологического компонента P300.

## Запись и завершение

Создаётся отдельная папка `session_дата_время_ID`:

| Файл | Содержание |
| --- | --- |
| `session.json` | Испытуемый, план, версии/исходный коммит, параметры, EEG XML, исход завершения |
| `eeg.csv` | Все исходные EEG-каналы и исходные LSL timestamps за всю сессию |
| `events.jsonl` | Маркеры с исходным временем и временем получения, переходы состояния |
| `trial_001/upstream_run.json` | Полный оригинальный экспорт пробы: EEG, события, параметры, эпохи и сводка |
| `trial_001/epochs.npz` | Многоканальные эпохи ROI, классы стимулов и временная ось; без pickle |
| `trial_001/erp_sums.npz`, `erp_unified.csv`, `erp_numbers.csv` | Поточечная сумма эпох по объектам: единый массив и одно число на объект |
| `trial_001/result.json` | Цель, рассчитанный объект, оценки, пригодные эпохи и статус пробы |
| `stim_control.json` | Оригинальный управляющий файл PsychoPy |

Запись выполняется отдельным потоком с ограниченной очередью. Переход на
другой EEG, отсутствие свежих отсчётов более трёх секунд, потеря маркеров,
неожиданная cue-цель, завершение стимулятора или ошибка записи прерывают
сессию с диагностикой. После восстановления оборудования создавайте новую
сессию. Кнопка **Остановить и закрыть архив** сохраняет текущую прерванную
пробу с `status=interrupted` и завершает собственный процесс стимулятора.

`recording_complete` означает штатно закрытый архив без ошибки записи.
`protocol_complete` означает, что выполнены все запланированные пробы.
При ручной остановке первое может быть true, второе будет false.
При аварийном завершении процесса исходный `recording_complete=false`
позволяет отличить незавершённый архив.

Исходная запись CSV во вкладке EEG работает независимо от записи сессии.
Алгоритм синхронизации Пронина не заменён; timestamps исходной EEG сохраняются
без коррекции, для аудита записывается также исходное время каждого маркера.
Полный оригинальный экспорт содержит его параметры выравнивания.

## SSVEP

Кнопка **Готовый протокол P300 / SSVEP** запускает исходный операторский GUI
Пронина из общего комплекса. Он сохраняет свои этапы, алгоритмы, формат
архивов и требования к мигалке, COM-порту и .NET 8. Он управляется собственным
протоколом и не запускается одновременно с единой P300-сессией.

Аппаратная SSVEP-часть не эмулируется в рабочем эксперименте. Отслеживание
взгляда в составе и интерфейсе комплекса отсутствует по уточнённому заданию.

## Проверка

Автоматические тесты используют только числовые фикстуры и генераторы
Пронина для проверки ПО, не обучают пользовательскую модель. Проверены
повторяемость плана, сохранность сырых данных, последовательность двух проб,
исходные решения P300, блокировка недостаточных данных, прерывание записи,
потеря EEG, падение стимулятора и защита существующих архивов от перезаписи.
Для реальных локальных LSL-сокетов: `RUN_LSL_NETWORK=1` и `pytest tests`.

Без EEG-источника кнопка старта показывает причину отказа. Исходная отдельная
синтетическая батарея доступна во вкладке «Запуск и проверка» и не выдаётся
за запись реальной EEG или оценку качества на человеке.
